`@ui-sdk/web` gives you components such as Select, Dialog, and Tabs as custom elements, built on ui-sdk's behaviors. They handle interactions, focus, and ARIA attributes. You write the HTML and styles.

Import the components you need to register their tags, add them to your page, and style them with your own CSS. The examples use Tailwind CSS.

## Explore the Components

Browse [Components](./components) to find what you need. Each page shows the component's parts, examples of what you can do with it, and its API.

The [Using Components guides](./parts-and-composition) cover patterns the components share, such as composing parts, handling state, and styling.

For a component of your own, start with [Build a Component](../core/build-a-component), then [render its parts as custom elements](./rendering).

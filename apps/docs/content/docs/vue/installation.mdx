Start with an app using Vue 3.5 or newer.

## Install the Packages

```bash
npm install @ui-sdk/vue @ui-sdk/core
```

`@ui-sdk/vue` provides the Vue components. `@ui-sdk/core` provides their behavior and is a peer dependency. Install both so the components and any helpers you use share one copy of the core.

## Import a Component

Import each component from its own entry:

```ts
import { Button } from "@ui-sdk/vue/button"
import { Toggle } from "@ui-sdk/vue/toggle"
```

A Dialog has separate parts for its trigger, content, and title. Import those parts from the same entry:

```ts
import { Dialog, DialogContent, DialogTitle, DialogTrigger } from "@ui-sdk/vue/dialog"
```

Each [component page](./components) lists the parts you can use.

## Add Your Styles

Components are unstyled. The examples use Tailwind CSS, but you can use your app's CSS too. [Styling and Animation](./styling-and-animation) covers both approaches.

You can render your first component without setting up a provider, importing a UI SDK stylesheet, or adding a portal root. [Server Rendering](./server-rendering) covers rendering the initial HTML and adding interactions during hydration.

## Right to Left

Set `dir="rtl"` on the page or a container. Arrow keys and popup placement follow that direction without a provider. Use logical CSS properties, such as `padding-inline-start`, for your styles.

Continue with [First Component](./first-component) to add a working toggle to your app.

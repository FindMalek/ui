## 1. Ask for Access

Ping @shadcn in #project-ui-sdk on Slack to request access to the private preview.

## 2. Install the Packages

shadcn will send you an `.npmrc` configuration. Copy it into `~/.npmrc` in your home directory. If the file already exists, add the new lines to it.

Then install the packages. For React:

```bash
npm install @ui-sdk/react @ui-sdk/core
```

## 3. Set Up Your Agent

Copy this prompt into `AGENTS.md` in your project root, then ask your agent to start building:

```text
This app uses ui-sdk. Before using a component, read
node_modules/@ui-sdk/react/docs/llms.txt. For a component ui-sdk doesn't ship, read docs/core.md
("Build a Component", "All Behaviors") and docs/rendering.md in the same folder.
```

## 4. Send Feedback and Suggestions

If you have feedback or suggestions, please ping @shadcn in #project-ui-sdk on Slack.
